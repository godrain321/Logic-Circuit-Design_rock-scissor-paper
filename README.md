# Logic-Circuit-Design_rock-scissor-paper
Sequential logic circuit design for a Rock-Paper-Scissors game using FSM and Gate-level optimization
<img width="940" height="448" alt="image" src="https://github.com/user-attachments/assets/8f2af188-8c39-4956-9242-57454c7e6915" />

using simulator: circuitverse

설계한 게임에 대한 기본적인 로직은 다음과 같습니다.
1.	파란색 불이 1분 빨간색 불이 10초 들어온다.
2.	파란색 불이 들어왔을 때 는 대기상태. 빨간불이 들어왔을 때 가위 바위 보 중 하나의 버튼을 누른다.
3.	만약 빨간불이 들어왔을 때 아무 버튼도 누르지 않으면 그 사람이 진걸로 판단.
4.	빨간불 이후 파란불이 들어왔을 때 누가 이겼는지 승패를 알려줌.
   
이 프로젝트는 ai를 쓰지 않고 직접 진행하였습니다. 가위바위보 입력판단부, 승패 판단 조합회로, 승패 출력, 빨간색 파란색 펄스 출력기, 간단한 카운터 설계를 통해 직접 설계한 후 circuitverse 시뮬레이터를 통해 시뮬레이션을 진행하였고 정상 작동하는 것을 직접 확인하였습니다.
